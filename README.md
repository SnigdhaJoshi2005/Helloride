# HelloRide 🚖🛵📦

HelloRide is a modern, comprehensive multi-service platform designed to simplify transportation and delivery. Built with speed and user experience in mind, HelloRide offers a seamless way to book rides, deliver parcels, and order food, all in one place.

## 🌟 Key Features

- **Ride-Sharing:** Quick and reliable Bike and Car rides at your fingertips.
- **Parcel Delivery:** Secure and timely delivery of your packages across the city.
- **Food Delivery:** Order your favorite meals from top-rated local restaurants.
- **Partner Program:** Opportunities for drivers (Bike & Car) to earn and grow with us.
- **Interactive Blog:** Stay updated with the latest news, travel tips, and service updates.
- **Responsive Design:** Optimized for a premium experience on both desktop and mobile devices.
- **Dynamic Animations:** Engaging UI with smooth animations for a premium feel.

## 🚀 Tech Stack

- **Frontend:** [React 19](https://react.dev/)
- **Build Tool:** [Vite](https://vitejs.dev/)
- **Routing:** [React Router DOM v7](https://reactrouter.com/)
- **Styling:** Custom Vanilla CSS3
- **Email Service:** [EmailJS](https://www.emailjs.com/)
- **Linting:** ESLint

## 🛠️ Installation & Setup

To get a local copy up and running, follow these simple steps:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/SnigdhaJoshi2005/Helloride.git
   ```
2. **Navigate to the project directory:**
   ```bash
   cd Helloride
   ```
3. **Install dependencies:**
   ```bash
   npm install
   ```
4. **Start the development server:**
   ```bash
   npm run dev
   ```
   The app should now be running at `http://localhost:5173`.
